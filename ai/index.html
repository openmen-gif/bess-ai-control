⚡ 3단계 빠른 시작

  1. MCP 서버 등록

    Claude Code에서 아래 한 줄이면 끝나요. 다른 MCP 클라이언트는 Streamable HTTP 주소로 https://bess-ai-control.work/api/mcp를 등록하면 돼요.

    claude mcp add --transport http bess https://bess-ai-control.work/api/mcp

  2. 전문가 찾기 — list_experts

    본부(CTO·CFO·COO)로 거를 수 있어요. 비우면 82명 전체예요.

    입력
    { "division": "CTO" }
    실제 응답(앞부분)
    BESS EPC 전문가 23명 (CTO)
- CTO-100 · bess-agent-framework (기술본부 (CTO 산하)): BESS EPC AI 에이전트 설계 프레임워크. v6.1 가이드라인 준수
- AIM-001 · bess-aiml-engineer (기술본부 (CTO 산하)): AI/ML 예측모델, 최적화 알고리즘, SOC/SOH 예측, …
- BAT-001 · bess-battery-expert (기술본부 (CTO 산하)): 배터리 사양 선정, 열화 분석, SOC/SOH, BMS, …
…

  3. 지식 읽기·질문 — get_expert_definition · ask_expert

    2단계에서 찾은 ID로 그 전문가의 역할 정의 전문(BAT-001 기준 약 11KB)을 읽거나, 바로 질문할 수 있어요.

    입력 — 정의 읽기
    { "agentId": "BAT-001" }
    실제 응답(첫 줄)
    당신은 BESS EPC 분야의 "bess-battery-expert" (기술본부 (CTO 산하)) 전문가입니다. …
    입력 — 질문하기
    { "agentId": "BAT-001", "question": "LFP 셀 SOH 80% 도달 사이클을 25도와 35도 운전에서 비교해 주세요" }

    응답은 그 전문가 관점의 한국어 답변 텍스트예요. agentId를 비우면 CEO-001(전체 조율 담당)이 답해요.
