1. rclone-backup 앱(Google 계정 연결)

rclone-backup 은 이 사이트 운영자 본인의 PC 작업 폴더를 운영자 본인의 Google Drive 에 백업하기 위한 개인용 도구입니다. 일반 사용자에게 제공하지 않습니다.

  • 요청 권한: Google Drive 파일 접근(백업 파일을 올리고 내려받기 위한 용도). 본인 Google 계정에만 사용합니다.
  • Google 사용자 데이터는 백업·복원 외의 목적으로 사용하지 않으며, 제3자에게 제공·판매·공유하지 않습니다.
  • 인증 토큰은 운영자 PC 에만 저장되고 외부 서버로 전송하지 않습니다.
  • 백업 데이터는 운영자 본인의 Google Drive 에만 저장되며, 민감한 내용은 암호화해 보관합니다.
  • 연결 해제: Google 계정 → 보안 → 타사 앱 액세스에서 언제든 권한을 취소할 수 있습니다.

rclone-backup 의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

2. 웹사이트 이용 시

  • 회원가입·로그인이 없으며 이름·연락처 등 개인정보를 수집하지 않습니다.
  • AI 질의 기능에 입력한 내용은 답변 생성을 위해 처리되며 별도 저장하지 않습니다. 남용 방지를 위해 접속 IP 기준 이용 횟수만 일시적으로 셉니다.
  • 호스팅 사업자(Cloudflare)가 보안·운영 목적의 접속 기록을 처리할 수 있습니다.

3. 문의

Privacy Policy (English summary)

rclone-backup is a personal tool used only by the owner of this site to back up the owner's own files to the owner's own Google Drive. Google user data is used solely for backup and restore, is never shared with or sold to third parties, and OAuth tokens are stored only on the owner's computer. Use of Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The website itself has no accounts and does not collect personal information.
